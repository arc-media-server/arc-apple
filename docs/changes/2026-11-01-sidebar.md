# Sidebar instead of top tabs

## What changed

The places (Search, Home, the Watchlist and libraries in the profile's order, Playlists and
Settings) are now in tvOS's sidebar, as Apple's own apps and Plex for Apple TV have them, using
tvOS 18's adaptable sidebar (`.sidebarAdaptable`) with an icon for each. Back from the top of a
page opens the sidebar; moving down it opens each place.

## Decisions

- The app now needs tvOS 18 or later (it was 17). Every Apple TV that runs tvOS 17 runs 18, so
  no device is left out. The owner asked for the sidebar (1 November); this replaces the top
  tabs noted in 2026-11-01-browsing.md and on arc-media-server#80.

## Logging

No change.
