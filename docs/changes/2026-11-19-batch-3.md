# Batch 3: library tabs, subtitle timing, finding Arc, card captions, the new logo

Built on batch 2 (#25), one commit per change.

## Library tabs

The Recommended / Browse / Collections (and Folders) tabs were taller than the Sort and Filter
buttons beside them and sat close to the posters. They now use the season tabs' smaller style
(reused, not a new one) in a slightly tighter glass capsule, and the grid starts 24 points lower,
so a focused poster no longer grows into the bar. Owner's request, 19 November.

## Subtitle timing

The player's Subtitles menu gains a Timing section, as the web and Android players have:
Show 0.5s Earlier, Show 0.5s Later and Reset Subtitle Timing, under a heading such as
"Timing: +1.5s (later)". Up to ten seconds either way, kept per file and track for this playback
only (not saved), as on the web and Android. Only text subtitles, which the app draws itself;
picture subtitles are part of the video, so the section doesn't show for them.

**Decisions:** the name and value style are the owner's decision on arc-media-server#479
(19 November): "Timing" inside the Subtitles menu, "Subtitle Timing" elsewhere, values as
+1.5s / −0.5s with a true minus and no space, and "(earlier)"/"(later)" beside the value.
Plex's Apple TV app was not checked for its wording.

## Find Arc on the network

The first screen ("Connect to your Arc server") now looks for Arc on the home network and lists
what it finds under **On your network**, as the Android app does (arc-android
`docs/changes/2026-11-17-find-server.md`): choosing one connects, as typing its address did.

- **How:** Arc's `GET /api/v1/discover` (no sign-in, home network only, identity/name/version).
  Apple TV apps may make plain HTTP requests to the local network: the app already has
  `NSLocalNetworkUsageDescription` and allows HTTP, so nothing new is asked of the viewer. As on
  Android, the Apple TV asks each address of its own network on port 8099: private networks only
  (10/8, 172.16/12, 192.168/16), at most its own /24, 48 at a time with short timeouts.
- **What counts as Arc:** only `product: "arc"` with an API version; each server once, by id.
- **On screen:** a spinner while searching; each server as it answers (name, then address and Arc
  version); the first takes the focus unless an address is being typed. None: "No Arc server
  answered on this network. Type its address above." and **Search Again**. Off a home network the
  section isn't shown. The same words as Android.
- **Code:** `ArcKit/Discovery.swift` (addresses, the scan; shared logic, tested on Linux),
  `ArcTV/App/LocalNetwork.swift` (the Apple TV's own address), `ServerView`.

**Decisions:** port 8099 only and the /24 limit, as Android (a server on another port is typed).
Bonjour isn't used: Arc doesn't advertise it, and the HTTP probe is what every Arc TV app shares.

**Limits:** not tried on an Apple TV or a real network; Wi-Fi with client isolation hides Arc
from any search (typing still works); IPv6-only networks aren't searched.

## Card captions move with the lift

tvOS's `.card` grows about a tenth when focused, so the title and year under a poster sat
against the artwork. They now slide down 22 points with it (`belowLiftedCard`), as tvOS's own
lockups do: posters and wide cards, collection tiles, episodes (and their summary), extras and
Watch Together rooms. Owner's request, 19 November. The distance may want tuning on a real TV.

## The new logo, app icon and Top Shelf

The app still drew "Arc" in the old teal gradient. It now uses the logo set the owner chose on
13 November (arc-media-server `docs/brand`), white with no colour, as the Android app did on
16 November: the main logo on the server, sign-in and profile screens, the stacked one in About
(SVGs in `Assets.xcassets`, kept as vectors). The app had no icon: it now has tvOS's layered icon
(the white TV over the icon's near-black gradient, as front and back layers so it moves with
focus) and the Top Shelf images (the main logo), drawn from the same SVGs with Chromium. The
unused teal colours are gone from `Theme.swift`.
